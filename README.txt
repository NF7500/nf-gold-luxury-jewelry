# NF Gold & Luxury Jewelry — GitHub Pages

## Installation
1. Remplacez votre `index.html` par celui fourni ici.
2. Envoyez le dossier `assets` avec `hero-visual.jpg` et `necklace-visual.jpg`.
3. Sur GitHub: **Settings → Pages → Deploy from branch → main / root**.
4. Attendez quelques instants puis ouvrez votre adresse GitHub Pages.

Le visuel fourni a été découpé en deux images pour reproduire le design:
- `assets/hero-visual.jpg` = partie principale du hero
- `assets/necklace-visual.jpg` = section French Craftsmanship
